# 各駅停車

每天一站学日语的 PWA：五十音、N5 词卡、语法闯关和每日打卡。这个仓库是构建产物，用 GitHub Pages 托管。

录音由 Microsoft Edge 朗读服务的 Nanami、Keita 语音生成，仅供个人学习使用。

粤语音桥的粤拼来自 [rime-cantonese](https://github.com/rime/rime-cantonese) 的 jyut6ping3 字表和词表（CanCLID，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)），经筛选加工；生成时用 OpenCC（Apache-2.0）转换字形，用 KANJIDIC2（EDRDG，CC BY-SA 4.0）判断音读。

声调线的数据改编自 [Kanjium](https://github.com/mifunetoshiro/kanjium) 的 accents.txt，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 授权；改动是筛选词条、补充词表没有的词，并在有多种读法时选用和录音一致的一种。改编后的声调数据同样按 CC BY-SA 4.0 授权。
